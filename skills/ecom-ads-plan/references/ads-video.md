# 阶段 4（投放侧）：广告视频投流

素材本身的生成（分镜、生成提示词、前三秒留存检查）由 `ecom-video-creative` 技能负责，见该技能的 `references/video-production.md`；素材编号在这两个技能之间必须一致。

目标：从选品和素材出发，产出**可以直接在广告后台执行的投放结构、素材分镜脚本、出价预算与止损规则**。投放动作本身由人工在平台后台完成——本阶段只交付方案、脚本和判定规则。

## 投放前必须确认

缺任何一项都先回问，否则方案只能给通用建议：

- 投放平台与版位：TikTok / Meta / Google / Amazon Ads / Shopee Ads 等，视频优先的版位与图文版位策略不同。
- 投放目标：测品 / 放量 / 清库存 / 拉新 / 保 ROAS，目标不同则出价与预算分布完全不同。
- 经济模型：客单价、商品成本、履约费、平台佣金、退货率 → 算出**保本 ROAS = 1 / 毛利率**，这是出价的锚。
- 素材库存：现有视频数量、成片时长与比例、能否批量产出（决定测试轮次）。
- 承接：Listing / 落地页是否就绪、库存是否够放量、价格与促销是否到位。
- 合规：平台广告政策、素材版权与音乐授权、达人合作披露要求。

## 投放结构

命名规范统一，后面复盘才拉得出数据：

```text
campaign   : {平台}_{站点}_{目标}_{品类}_{开始日期}     例：TT_US_测品_家居_20260914
ad_group   : {受众或素材方向}_{出价方式}                例：素材A_低出价
ad         : {素材编号}_{版本}_{比例}_{时长}             例：V012_v3_9x16_15s
```

- 一个 campaign 只测一个变量维度（素材 / 受众 / 出价三选一），否则测不出结论。
- 冷启动阶段不要频繁改预算和出价，先让它跑完学习期（平台不同，通常 20–50 个转化）。
- 分层放量：测出的优胜素材进放量组，单纯加预算不改素材；加预算每次不超过 30% 避免重置学习期。

## 素材分镜脚本

短视频的前 3 秒决定大部分成本，脚本按这个结构写：

1. **3 秒钩子**——三选一：痛点直击 / 效果反差 / 身份代入（目标人群的自称）。
2. **场景**——真实使用场景，避免纯棚拍产品图。
3. **卖点排序**——最多 3 个卖点，第一个必须与钩子呼应。
4. **证明**——实测、对比、资质、销量或评价，用于降低下单疑虑。
5. **CTA**——明确动作与利益点（限时、赠品、免运费）。

输出成分镜表，字段固定：

| 时间码 | 画面/运镜 | 字幕 | 口播 | 音效/BGM | 备注 |
|---|---|---|---|---|---|
| 0:00–0:03 | | | | | 钩子 |

同时给出：横版 16:9 与竖版 9:16 两版适配建议、成片时长（15s / 21s / 30s 各一条用于测试）、以及 A/B 变体清单（每条视频只变一个元素：钩子 / 卖点顺序 / CTA）。

## 出价与预算

- 成本上限推导：`CPC上限 = 客单价 × CVR × 毛利率`；`CPA上限 = 客单价 × 毛利率`。
- 保本 ROAS 是硬约束，低于它的组不追加预算。
- 单素材测试预算：给到能产出最小可判定转化量（经验值 3–5 个转化）的预算再判优，避免样本不足就关停。
- 测品节奏建议：第 1 轮广度测素材（多条小额），第 2 轮对优胜素材做受众与出价组合，第 3 轮放量；每轮结束做一次留优淘劣。

## 止损与判优规则

写成显式阈值，越界才动，不凭感觉：

- 花费达到单素材预算 X% 且无转化 → 关停。
- CTR 显著低于同组均值（如低于 60%）且已有足够曝光 → 暂停素材。
- 加购/结账率正常但 CVR 低 → 优先查承接页与价格，而不是继续加预算。
- ROAS 连续两个观察窗低于保本线 → 降预算或换素材方向。
- 出现素材违规警告或审核不通过 → 停止投放并排查合规，不要重复提交。

## 数据看板字段与阈值参考

曝光、点击、CTR、CPC、CVR、CPA、花费、广告收入、ROAS、ACOS、TACOS、完播率、3s 留存、加购率、退货率。阈值必须按品类和站点基线设定，不要直接套用通用值——先取该店铺自身近 30 天基线，再看偏离度。

## 交付物

1. 投放结构表（可直接照着新建 campaign/ad group/ad）。
2. 素材分镜脚本（含 A/B 变体清单与拍摄要点）。
3. 预算与出价表（含保本 ROAS 与 CPC/CPA 上限推导过程）。
4. 判优与止损规则（阈值表）。
5. 待人工执行清单：新建 campaign、上素材、设预算、开投、违规处理。
6. 合规检查项：绝对化用语、功效宣称、before-after 对比、未成年人导向、版权音乐、达人披露。
