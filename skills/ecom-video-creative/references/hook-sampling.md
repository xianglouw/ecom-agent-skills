# 阶段 4 · 爆款开场采样口径

`hot_hooks.py` 的结果好不好，全看采样表填得规不规范。**三个人用三种采法混在一张表里，套路占比就是噪声。**

这份是给**去采集的人**看的，不需要懂脚本。按下面做完，把表交给运营跑一遍就行。

## 一、采什么：黄金三秒的定义

只采**视频开口到第 3 秒结束**之间，观众看到和听到的内容：

- **有口播就记口播**，屏幕上有字幕就接着记（例：`¿Sigues perdiendo tiempo? ｜ 别再浪费时间了`）。
- **只有字幕没有口播**（很多纯画面带货是这样），就记字幕。
- **照抄原话**：不翻译、不改错别字、不补语气词。翻译过的台词进不了统计——脚本要靠原文的特征词判断套路。
- **一句话 3 秒念不完的，只记念得完的部分**，不要为「意思完整」把整句都抄进来；拿不准就按开口后的第一句完整话算。

## 二、在哪采

按性价比排序，前两条是主力：

1. **自家投放后台**里跑得好的素材——最容易被忽略但最重要，因为那是你自己的数据。
2. **平台榜单**：TikTok Creative Center、抖音热榜与带货榜、Shopee 内容榜、各平台官方创意中心。
3. **竞品账号**近 14 天的带货视频。
4. **达人合作方**给的历史素材与脚本。

一个周期内**至少覆盖两个来源**：只用榜单容易采成一堆大号套路，跟自己的受众不一定是一回事。

## 三、筛什么、采多少

**符合这些才进表**：是带货视频（挂了商品或有明确转化目标）；有表现数据（播放 / 销量 / 点赞至少一项）；近 14 天；不重复（同一个作品只采一次）。

**排除**：纯娱乐段子、品牌形象片、直播切片、明显搬运的号。

| 项 | 要求 | 为什么 |
|---|---|---|
| 每个组合的条数 | **≥ 30 条**（少于 20 条脚本会提示样本偏小） | 条数太少，套路占比会跳来跳去 |
| 采样单元 | **站点 × 类目** 算一份 | 拉美户外装备和美国汽车用品混着算没意义 |
| 时间窗 | **近 14 天**，一次采完 | 跨月混采会把两个周期的风向搅在一起 |
| 频率 | **每两周一次**；上新类目前补一次 | 套路会换人，排行得跟着更新 |
| 填表时间 | **当天采当天填** | 隔天补最容易把数字记错、台词记串 |

新周期**另存一份新表**，不要往上一周期的表里追加。

## 四、每个字段怎么填

| 列 | 必填 | 怎么填 | 常见错法 |
|---|---|---|---|
| 平台 | | TikTok / Reels / Shorts / Shopee / 站内信息流 | 同一平台写成好几个名字（TT / tiktok / 抖音国际版） |
| 站点 | | 两位国家码：`MX` `BR` `VN` `JP` `TH` `US` | 写中文或城市名；**必须与产品表、市场风格库写法一致** |
| 语种 | | 这条台词实际用的语言 | 填成站点默认语言，但视频其实是英语 |
| 类目 | | 与产品表里的类目写法一致 | 写太细（「户外天线支架」）导致同类凑不够 30 条 |
| **前3秒台词** | ✔ | 原文照抄，见第一节 | 填翻译、填整条文案、自己润色 |
| 播放量 | | **平台显示的数字原样填**，不换算成万、不估 | 写「18万」而不是 180000 |
| 销量 / 点赞 | | 平台显示的，没有就留空 | 把点赞数填到销量上 |
| 作品 | | 作品 ID 或链接，**要能点回去查** | 只写账号名，事后回查不到 |
| 采集日期 | | `YYYY-MM-DD`，同一批同一天 | 填成截图或导出的时间 |

数字宁缺勿造：**没有就留空**，脚本按有数据的行算平均；估一个数字反而会把排行带偏。

## 五、几个最容易犯的错

- **把翻译当原文**：脚本靠原文特征词（问号、`đừng`、`só`、`stop buying`）判套路，翻译过来全判不出来。
- **把整条文案当 3 秒**：会让「口播讲不完」的判断失真，也把非开场内容当成钩子。
- **跨站点跨类目混采**：占比会变成「谁采得多谁排前面」，而不是「谁更常用」。
- **只采头部大号**：头部品牌的玩法中小卖家学不来，也代表不了这个类目的普遍做法。
- **同一个作品重复采**：会把某个套路人为抬高；**一个周期采两次混在一张表**则把两段风向搅在一起。

## 六、采完之后怎么跑

先下模板（表头与脚本字段永远同步，别自己手敲列名）：

```bash
python3 scripts/hot_hooks.py --template hook_sampling.csv
```

填完交给运营跑：

```bash
python3 scripts/hot_hooks.py hook_sampling.csv \
  --hooks hook_patterns.csv --products products.csv --top 3 \
  --out hot_words.csv --out-xlsx hot_hooks.xlsx --out-md hot_hooks.md \
  --out-json hot_hooks.json --quarantine hot_hooks_issues.csv
```

拿到结果先看两处：

1. **报告里的「需要人工处理」**：认不出来的台词列在这里。**让采集的人自己归一次最准**——他看过原视频，比任何规则都清楚。
2. **`flags` 两条提示**：`unclassified_lines` 超过三成说明采样的语言或套路超出了内置线索，要补线索词；`small_sample` 说明条数还不够，先别急着定主推套路。

## 七、边界

- 采来的台词是**别人的素材**，只用来提炼套路与用词：不照抄原句、不搬画面、不盗 BGM，采完的表别外发。
- 去水印解析、作品批量提取这类工具**只用于研究**，导出的成片一律不进投放素材库。
- 套路占比说明的是「这个周期大家怎么开场」，**不代表这么写就一定有效**——真正该上哪条，要用你自己的 A/B 测出来。
