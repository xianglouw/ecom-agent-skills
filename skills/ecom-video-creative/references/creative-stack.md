# 阶段 4（形态侧）：素材形态选择与外部能力

分镜之前还有一步，也是最容易做错的一步：**这条素材该用哪种形态做**。
同一条卖点，做实拍、数字人、AI 生成、混剪还是图文，成本差十倍、周期差一周，能上的平台也不一样。
**形态选错，后面分镜写得再好也是白费。**

## 一、六种形态

| 形态 | 适合 | 别用在 | 本技能交付什么 | 出片靠什么 |
|---|---|---|---|---|
| **实拍口播** | 需要真人信任背书的品（母婴、保健、美妆、工具）、有样品、有出镜人 | 出镜人档期排不开、目标语种说不地道 | 分镜 + 口播稿 + 首帧要求 + 字幕 | 手机 / 相机自拍，或达人合作 |
| **数字人口播** | 要口播但没人出镜；要做多语种版本；要批量产出同一套话术 | 品需要「真人实测」的说服力；平台对数字人有额外要求而没做标注 | 口播稿 + 语速预算 + 口型对齐的分段文案 | 数字人工具 + 配音（克隆或 TTS） |
| **AI 生成镜头** | 缺场景空镜、缺特定环境（露营、雪地、厨房）、要概念画面 | 需要展示真实产品细节、需要前后对比实证 | 分镜 + 文生/图生视频提示词（可直连 12 家出片） | `video_render.py` |
| **AI 混剪** | 已有大量素材要复用；要做多个钩子变体；要快反测试 | 素材本身质量不过关、画面里带别家水印 | 钩子台词 + 分镜顺序 + 每段时长预算 | 混剪工具（按本技能给的时间轴拼） |
| **素材库剪辑** | 缺生活场景 B-roll、做氛围铺垫 | 用素材库画面冒充自己的产品实拍 | 每段要找什么的检索词 + 时长 + 与口播的对位 | 高清素材库检索下载 + 本地剪辑 |
| **图文** | 平台以图文带货为主；品靠外观或参数表就能说清；预算极低要铺量 | 需要演示效果、需要口播种草 | 首图钩子文案 + 图片脚本 + 文案与标签 | 图片生成 / 实拍白底图 + 排版 |

**判定顺序**（顺着问，第一个「是」就是答案）：

1. 有样品、有可信出镜人、话术能说地道 → **实拍口播**（信任度最高，别轻易放弃）
2. 需要口播但没人出镜，或要铺多语种 → **数字人口播**
3. 只缺场景镜头 / 空镜 / 概念画面 → **AI 生成镜头**
4. 手上有能用的素材，只差换钩子 → **AI 混剪**
5. 缺生活场景 B-roll 铺氛围 → **素材库剪辑**
6. 这个平台就是刷图文的，或这个品靠图就能说清 → **图文**

形态不是单选题：常见组合是**口播 + AI 空镜 + 素材库氛围**剪成一条。但**钩子（前 3 秒）永远用信任度最高、最可控的那种形态**，别拿 AI 生成的模糊画面去当钩子。

## 二、外部能力对接

这些能力本技能不自己实现（要模型服务或要下载平台内容），但**每一个都要本技能先给出稿子、提示词或入参**才能开工。
下表写清「什么时候值得用、我们先给什么、红线在哪」。

| 能力 | 拿它干什么 | 什么时候值得用 | 我们先给出什么 | 红线 |
|---|---|---|---|---|
| **爆款采样** | 采本周期热门带货视频的前 3 秒台词，提炼套路与用词 | 每两周一次，或上新类目前 | 采集口径见 [hook-sampling.md](hook-sampling.md)；模板用 `hot_hooks.py --template` 下 | 只用于提炼套路与用词；不照抄原句、不搬画面、不盗 BGM；采完的表不外发 |
| **作品批量提取** | 批量拉某个账号的作品与音频做研究 | 研究竞品账号的选题与开场节奏时 | 要观察的维度与研究表结构 | 平台内容有版权，**只做内部研究**，不得二次发布、不得进投放素材库 |
| **去水印解析** | 下载平台原生视频做研究 | 同上，仅研究用途 | 要研究的片段清单 | ⚠️ **去水印成片绝不能直接投放**：平台原创度判定会命中，且涉及版权。研究完只留结论，不留成片 |
| **数字人**（照片 / 视频） | 没人出镜也能口播，或批量铺多语种 | 要铺量、要跑多语种、要快速测钩子 | 口播稿、语速预算、按句分段（口型对齐）、首帧表情与景别要求 | 用真人肖像必须有书面授权；按平台要求标注 AI 生成；不得让数字人冒充专家、医生或真实用户做功效背书 |
| **声音克隆** | 固定一个品牌音色，多语种复用 | 多语言版本要铺、希望音色统一 | 目标语种重写后的配音稿、断句标记、语速上限 | 克隆他人声音必须本人书面授权；不得克隆名人或平台达人声音 |
| **视频换脸** | 创意玩法、角色扮演类内容 | 品牌自有素材版权，且玩法本身就是卖点 | 镜头脚本 + 允许/禁止的换脸对象 | ⚠️ **风险最高的一项**：肖像权、平台对换脸的明确限制、可能被判虚假宣传。**默认不做** |
| **AI 混剪** | 文案 / 图片 / 已有素材 → 成片 | 要做多条钩子变体做 A/B，或热点要当天出片 | 钩子台词、分镜顺序、每段时长、字幕文本 | 复用他人素材同样有版权问题；成片要做原创度自检 |
| **AI 素材库** | 检索下载高清 B-roll | 缺生活场景、环境镜头 | 每段要找什么的检索词（用目标市场的说法，不是直译）+ 时长 | 注意素材库的商用授权范围；纯素材库拼贴的内容推荐会吃亏 |
| **文案生成视频** | 把一段文案直接变成成片 | 快反测试、预算有限、要日更 | 结构化分镜文案（本技能的分镜表可直接用） | 生成结果仍要过一遍前三秒留存检查，不能因为「自动生成」就跳检 |

**统一规矩**：① 先有稿再动工具，没有稿开工具出来的是一堆废片；② 多语种不是翻译，口播稿必须按目标语种重写并复测语速；
③ AI 生成内容按平台要求标注，**政策会变，不确认就按 `high` 交人工**；④ 授权（肖像 / 声音 / 音乐 / 素材库商用范围）没落实，素材不进投放队列。
工具选型、成本、账号权限是用户的事——本技能负责把稿子和入参准备到「拿过去就能开工」。

## 三、与投放的衔接

素材做完的最后一步是**变成能测的结构**，这部分与 [`ecom-ads-plan`](../../ecom-ads-plan/references/ads-video.md) 配合：

- **素材编号进 `ad` 命名**（`V012_v3_9x16_15s`），素材侧给的编号在投放侧原样用上，否则复盘对不上是哪条。
- **一个 campaign 只测一个变量**：钩子 / 卖点顺序 / CTA / 形态，同时变两个就归因不了。
- **形态也进对比**：同一个钩子分别做成实拍与数字人各一条，比完再决定长期用哪种——别照搬别人的结论。
- **判优用保本 ROAS 当线，素材衰减就换钩子重出**，不要一味加预算。

完整测法（各自看哪个指标、每条素材要跑到多少转化才判优劣）见 ecom-ads-plan 的「素材变量怎么设计」。
