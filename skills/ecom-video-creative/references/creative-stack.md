# 阶段 4（形态侧）：素材形态选择与外部能力对接

分镜脚本之前还有一步，而且是最容易做错的一步：**这条素材该用哪种形态做**。

同一条卖点，用实拍口播、数字人口播、AI 生成镜头、混剪、素材库剪辑还是图文，成本差十倍、周期差一周，
而且**能上的平台和能过审的概率都不一样**。形态选错，后面分镜写得再好也是白费。

这份手册只解决两件事：**怎么定形态**、**形态定好之后用哪个外部能力把它做出来**。
每种形态最终都要回到本技能的主流程——分镜、生成提示词、前三秒留存检查、多语种预算，一个都不能省。

## 一、六种素材形态

| 形态 | 适合什么品 / 什么场合 | 别用在 | 本技能交付什么 | 出片靠什么 |
|---|---|---|---|---|
| **F1 实拍口播** | 需要真人信任背书的品（母婴、保健、美妆、工具）、有样品在手、有出镜人 | 出镜人档期排不开、目标语种说不地道 | 分镜 + 口播稿 + 首帧要求 + 字幕 | 手机 / 相机自拍，或达人合作 |
| **F2 数字人口播** | 要口播但没人愿意出镜；要做多语种版本；要批量产出同一套话术 | 品需要「真人实测」的说服力；平台对数字人有额外要求而没做标注 | 口播稿 + 语速预算 + 口型对齐用的分段文案 | 数字人工具（照片转数字人 / 视频数字人）＋配音，声音用克隆或 TTS |
| **F3 AI 生成镜头** | 缺场景空镜、缺特定环境（露营、雪地、厨房）、要概念画面 | 需要展示真实产品细节、需要前后对比实证 | 分镜 + 文生/图生视频提示词（本技能可直连 12 家出片） | `video_render.py` 直连视频生成接口 |
| **F4 AI 混剪** | 已有大量素材要复用；要做多个钩子变体；要做「文案→成片」的快反测试 | 素材本身质量不过关、画面里带别家水印 | 钩子台词 + 分镜顺序 + 每段时长预算 | 混剪工具（按本技能给的时间轴拼） |
| **F5 素材库剪辑** | 缺 B-roll（生活场景、环境镜头）、做氛围铺垫 | 用素材库画面冒充自己的产品实拍 | 每段要找什么的检索词 + 时长 + 与口播的对位 | 高清素材库检索下载 + 本地剪辑 |
| **F6 图文** | 平台以图文带货为主；品靠外观 / 参数表就能说清；预算极低要快速铺量 | 需要演示效果、需要口播种草 | 首图钩子文案 + 图片脚本（每张说什么）+ 文案与标签 | 图片生成 / 实拍白底图 + 排版 |

**判定顺序**（按这个顺序问自己，第一个「是」的就是答案）：

1. 有样品、有可信出镜人、话术能说地道 → **F1 实拍口播**（信任度最高，别轻易放弃）
2. 需要口播但没人出镜，或要铺多语种 → **F2 数字人口播**
3. 只缺场景镜头 / 空镜 / 概念画面 → **F3 AI 生成镜头**
4. 手上有能用的素材，只差把钩子换一换 → **F4 AI 混剪**
5. 缺生活场景 B-roll 来铺氛围 → **F5 素材库剪辑**
6. 这个平台就是刷图文的，或这个品靠图就能说清 → **F6 图文**

> 形态不是单选题：常见组合是 **F1 口播 + F3 空镜 + F5 氛围** 剪成一条。
> 但**钩子（前 3 秒）永远用信任度最高、最可控的那种形态**——通常是实拍或数字人口播，
> 别拿 AI 生成的模糊画面去当钩子。

## 二、外部能力对接表

下面这些能力本技能不自己实现（要么要模型服务、要么要下载平台内容），但**每一个都需要本技能先给出提示词 / 脚本 / 入参**
才能开工。这张表写清「什么时候值得用、我们先给什么、红线在哪」。

| 能力 | 拿它干什么 | 什么时候值得用 | 本技能先给出什么 | 红线 |
|---|---|---|---|---|
| **爆款采样（榜单 / 热词）** | 采集本周期热门带货视频的前 3 秒台词，提炼套路与用词 | 每隔一个周期（建议两周）做一次，或上新类目之前 | 采集口径见 [hook-sampling.md](hook-sampling.md)（黄金三秒怎么算、采多少条、每个字段怎么填）；空白模板用 `python3 scripts/hot_hooks.py --template hook_sampling.csv` 下 | 采样只用于**提炼套路与用词**；不照抄原句、不搬画面、不盗 BGM；采完的表不外发 |
| **作品批量提取** | 把某个账号的作品 / 音频批量拉下来做研究 | 研究竞品账号的选题与开场节奏时 | 要观察的维度（钩子类型、时长、卖点顺序）与研究表结构 | 平台内容有版权，**只做内部研究**；不得二次发布、不得进投放素材库 |
| **去水印解析** | 下载平台原生视频做研究 | 同上，仅研究用途 | 要研究的片段清单 | ⚠️ **去水印后的成片绝不能直接投放**：平台原创度判定会命中，且涉及版权。研究完只留结论，不留成片 |
| **照片 / 视频数字人** | 没人出镜也能做口播，或批量铺多语种版本 | 要铺量、要跑多语种、要快速测钩子 | 口播稿、语速预算、分段（口型对齐按句切）、首帧表情与景别要求 | 用真人肖像必须**拿到本人书面授权**；用 AI 生成人物要在平台要求的位置标注；不得让数字人冒充专家、医生、真实用户做功效背书 |
| **声音克隆** | 固定一个「品牌音色」，多语种复用 | 有多语言版本要铺，且希望音色统一 | 配音稿（按目标语种重写后的版本）、断句标记、语速上限 | 克隆他人声音必须**本人书面授权**；不得克隆名人、平台达人声音 |
| **视频换脸** | 创意玩法、角色扮演类内容 | 品牌自己有素材版权、且玩法确实是卖点 | 镜头脚本 + 允许/禁止的换脸对象说明 | ⚠️ **风险最高的一项**：肖像权、平台对换脸的明确限制、可能被判虚假宣传。**默认不做**，非要做只用于品牌自有素材，并且在生成前逐条确认授权与平台政策 |
| **AI 混剪** | 文案 / 图片 / 已有素材 → 成片 | 要做多条钩子变体做 A/B，或热点要当天出片 | 钩子台词、分镜顺序、每段时长、字幕文本 | 复用他人素材同样有版权问题；混剪出来的成片要做原创度自检 |
| **AI 视频素材库** | 检索并下载高清 B-roll | 缺生活场景、环境镜头 | 每段要找什么的**检索词**（用目标市场的说法，不是直译） + 时长 + 与口播的对位 | 注意素材库的商用授权范围；被识别为纯素材库拼贴的内容，平台可能降低推荐 |
| **文案生成视频** | 把一段文案直接变成成片 | 快反测试、预算有限、要日更 | 结构化的分镜文案（本技能的分镜表直接可用） | 生成结果仍要过一遍前三秒留存检查，不能因为「自动生成」就跳检 |

### 用外部能力时的统一规矩

1. **先有稿，再动工具**。所有形态都从本技能的分镜 / 口播稿出发；没有稿就开工具，出来的是一堆废片。
2. **多语种不是翻译**。F2 / F6 尤其容易翻车：口播稿必须按目标语种重写，语速预算按该语种复测。
3. **AI 生成内容要标注**。用数字人、换脸、AI 生成画面时，按投放平台的要求标注；**平台政策会变，不确认就按 `high` 交人工**。
4. **一项能力一个合规判断**。授权（肖像权 / 声音 / 音乐 / 素材库商用范围）没落实，素材不进投放队列。
5. **本技能不替用户决定用哪个工具**。工具选型、成本、账号权限是用户的事；技能负责把稿子和入参准备到「拿过去就能开工」。

## 三、素材与投放怎么接上

形态和稿子做完，最后一步是**把素材变成能测的结构**。这部分与 [`ecom-ads-plan`](../../ecom-ads-plan/) 配合：

| 环节 | 怎么做 | 为什么 |
|---|---|---|
| **素材编号** | 进投放前给每条素材一个稳定编号（`V012`），并写清比例与时长 | 投放侧的 `ad` 命名要用它，否则复盘时对不上是哪条素材 |
| **一 campaign 一变量** | 一个测试 campaign 里只变一个东西：钩子 / 卖点顺序 / CTA / 形态 | 同时变两个，测出来的结论归因不了 |
| **测试轮次** | 每条钩子至少一条版本；同一 SKU 至少 2 个钩子对比 | 单条素材跑出来的数据说明不了问题 |
| **判优阈值** | 用保本 ROAS 当线：低于保本线的直接判「低效」 | 素材「好看」不等于「划算」 |
| **形态也进对比** | 同一个钩子分别做成 F1 与 F2 两条，比完再决定长期用哪种 | 数字人是不是真的比实拍差，得用自己市场的数据说话 |
| **素材衰减** | 素材表现下滑到阈值以下就换钩子重出，不要一味加预算 | 同一个钩子的受众会被吃干净 |
| **版位匹配** | 9:16 走短视频信息流，1:1 / 4:5 走广场与图文位；别把竖版裁成横版硬投 | 版位不对会白花钱 |

投放侧的结构、出价、预算、止损阈值见 [`ecom-ads-plan`](../../ecom-ads-plan/references/ads-video.md)；
素材维度的表现回归见 [`ecom-roi-review`](../../ecom-roi-review/)。

## 四、常见坑

- **形态选错**：花大价钱做数字人，结果这个品类用户就信真人实测——先按第一节的顺序问一遍。
- **拿 AI 生成画面当钩子**：前 3 秒是决定成本的位置，别用最不可控的形态占住它。
- **去水印的成片直接投**：平台原创度判定会命中，轻则不过审，重则影响账号。
- **换脸玩了再说**：这是唯一一项「授权没落实就绝对不做」的能力。
- **数字人不标注**：平台对 AI 生成内容的标注要求在收紧，不确认就按高风险处理。
- **只做一条素材就去投**：没有对比就没有结论，测不出该留哪个钩子。
- **素材库拼贴当原创**：纯素材库拼出来的内容缺少产品实证，推荐会吃亏。
