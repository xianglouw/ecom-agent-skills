# 阶段 4（生产侧）：多模态广告素材生产

目标：产品链接上线后，用文生图 / 图生图 / 图生视频 / 配音等模型（Seedance、Veo、Sora、Kling、即梦、nano-banana 系等）批量产出**符合产品定义、投放市场人群习惯与媒体风格**的广告短视频，并让每条素材都过一遍**前三秒留存检查**再进投放队列。

本文件解决「怎么生成、生成成什么样」；投放结构、出价预算与止损规则见 [ads-video.md](ads-video.md)。

## 前置条件

- **Listing 已上线**：落地页、价格、库存、促销到位。素材先于落地页生成的代价是点击进来看到的价格对不上，退款和差评会反噬。
- **产品定义齐**：品类、目标人群、3 个以内卖点、证明材料、CTA 利益点。缺卖点的素材只能拍成产品展示，钩子无从谈起。
- **风格库就绪**：投放市场的语言、平台、节奏、画面风格、出镜者、场景、调性、禁忌——这些**必须来自市场风格库文件**，不能靠模型凭印象编。
- **合规词表就绪**：绝对化用语、功效宣称、平台特殊限制。

## 工具链分工

按「理解 → 出图 → 出片 → 上线」四段拆，每段用最适合的模型，不要指望一个模型端到端：

| 环节 | 能力 | 代表工具 | 输入 | 输出 | 注意 |
|---|---|---|---|---|---|
| 竞品与风格拆解 | 视觉分析、排版与摄影风格拆解、比价参考 | store-teardown、比价检索类工具 | 竞品店铺/详情页截图、榜单链接 | 风格要点、差异化机会 | 只做参考，不要照搬他人素材与文案 |
| 关键帧与静图 | 文生图、图生图、视觉分析 | nano-banana 系、电商美工类工具 | 本文件产出的画面描述 + 产品实拍图 | 首帧图、场景图、Banner | 产品外观必须与实物一致，改色改型会引发退货 |
| 视频生成 | 图生视频、文生视频、首尾帧控制 | Seedance 2.5 / Veo / Sora / Kling / 即梦等 | 分镜表 + 生成提示词 + 首帧图 | 3–10 秒镜头片段 | 一次只生成一个镜头，多镜头一次出的一般不可用 |
| 配音与字幕 | TTS、口播克隆、多语种字幕 | 各平台 TTS / 数字人 | 分镜表里的口播与字幕列 | 目标语种配音音轨 + 字幕文件 | 用目标市场的本地口音，机器腔英语在西语市场很违和 |
| 剪辑与合成 | 拼接、卡点、字幕烧录、调色 | 剪辑软件或自动化流水线 | 镜头片段 + 音轨 + 字幕 | 成片 mp4 | 按 `{素材名}` 规范命名，方便投放端与复盘端对齐 |
| 上传归档 | 素材上传到素材库/广告后台 | 上传类工具（如即梦 VOD 上传等） | 成片文件 | 素材库资源 ID | 上传后回填素材 ID 到素材台账，否则复盘拉不齐数据 |

工具能力以实际可用版本为准；本文档规定的是**各环节的输入输出契约**，换工具不影响流程。

## 分镜骨架

固定五段，第一镜永远是 3 秒钩子，不允许把钩子往后挪：

| 镜头 | 15s | 21s | 30s | 作用 |
|---|---|---|---|---|
| 1 钩子 | 0–3s | 0–3s | 0–3s | 拦住刷走 |
| 2 痛点场景 | 3–7s | 3–8s | 3–10s | 让目标人群确认「说的是我」 |
| 3 产品演示 | 7–11s | 8–14s | 10–18s | 产品怎么解决问题，实拍优先 |
| 4 证明 | 11–13s | 14–18s | 18–25s | 销量、评价、实测、资质 |
| 5 CTA | 13–15s | 18–21s | 25–30s | 只留一个动作与利益点 |

同一 SKU 至少出 2 个不同钩子的版本，素材之间只变一个变量（钩子类型 / 卖点顺序 / CTA），否则测不出结论。

## 前三秒留存法则

短视频的成本结构决定了：**前 3 秒留不住人，后面拍得再好也没有播放机会**。硬性检查项如下，脚本 `video_brief.py` 会自动跑一遍：

| 检查项 | 规则 | 不通过的典型后果 |
|---|---|---|
| 首帧有主体 | 第一帧就是产品主体、使用动作或冲突画面 | 前 3 秒划走 |
| 禁止开场方式 | 不用 logo 开场、片头动画、黑屏、空镜、慢镜头、静态白底图 | 完播率断崖 |
| 前 3 秒有动态 | 首帧描述里必须包含动作或画面变化（拿、倒、撕、开、对比、出现…） | 像图片轮播，点击率低 |
| 字幕可读 | 前 3 秒必须有字幕，静音刷到的用户要能看懂 | 静音环境下等于没讲 |
| 口播讲得完 | 3 秒口播不超过该语种语速上限（中文约 13 字，英语约 8 词，西语/葡语约 8 词） | 话没讲完就被划走 |
| 钩子类型明确 | 必须取自钩子模板库，并写明留存理由 | 素材全靠感觉，无法复盘 |
| 本地化 | 文案为目标市场语言，机器翻译腔要重写 | 本地用户一眼看出是外来卖家 |
| 合规 | 无绝对化用语、无功效承诺、无未证实对比 | 审核不过或被罚款 |

**钩子类型库**（示例库见 `examples/hook_patterns.csv`，按品类继续扩充）：

| 类型 | 适用 | 首帧要点 |
|---|---|---|
| 痛点直击 | 功能型、复购型产品 | 正在被麻烦困扰的画面 |
| 结果前置 | 效果可视化的产品 | 前后对比的「后」 |
| 价格锚点 | 性价比定位 | 价格与产品的同框 |
| 身份代入 | 人群标签清晰的品类 | 目标人群的真实日常 |
| 反常识 | 同质化严重的红海品类 | 否定动作 + 被划掉的旧做法 |
| 对比测试 | 有可见差异的产品 | 两方案并排 + 手部动作 |
| 场景代入 | 使用场景固定的产品 | 真实生活场景 |
| 悬念提问 | 有认知门槛的产品 | 疑问表情 + 推近产品 |

**常见失败模式**：把品牌介绍放开头、前 3 秒讲参数、一条视频塞 5 个卖点、钩子与落地页承诺不一致、只有配乐没有口播和字幕、全程一个长镜头。

## 地区与人群适配

同一个产品在不同市场，素材要换的不只是语言：

- **语言与口音**：拉美西语与西班牙西语用词差异明显，巴西用葡语；配音优先找当地口音，字幕与配音要一致。
- **平台与节奏**：TikTok / Reels 前 3 秒更吃强动态与快切；信息流图文版位可以缓一些，但钩子逻辑不变。
- **场景与人物**：出镜者年龄、家庭成员结构、居住环境要贴近当地真实生活，用明显非本地的场景会掉转化。
- **价格与促销表达**：当地币种、当地常见的促销话术（免运费、分期、买二送一）优先于「立减 10%」这类通用表达。
- **禁忌**：宗教、政治、国旗、地域玩笑、体型与肤色相关的玩笑，都列进风格库的禁忌字段，生成与剪辑前各查一次。

**风格库必须可追溯**：每条风格结论带来源（本地达人素材复盘、平台后台数据、当地团队反馈）与获取日期，不能靠模型印象编造——`video_brief.py` 遇到风格库缺失的市场直接标 high flag，不套用其他市场习惯。

## 交付物

1. **分镜脚本表**（CSV）：一条素材一行镜头，含时间码、画面、字幕、口播、留存说明。
2. **生成提示词**：每条素材一段，可直接粘给文生视频模型，含主题、风格、规格、分镜、字幕、钩子、配乐、合规约束。
3. **前三秒检查结果**：通过 / 不通过及具体原因，不通过的必须改完再生成。
4. **素材台账**：素材名、SKU、市场、钩子类型、版本、时长、比例、生成模型、成片路径、素材库 ID。
5. **待人工确认清单**：本地化文案、价格与促销口径、合规表述、肖像与音乐授权。

## 生成与验收

- **一次一个镜头**：多镜头一次性生成通常连不上、动作也乱，按分镜逐镜生成再拼接。
- **先出首帧再出视频**：钩子镜头先用图模型出 3–5 张候选首帧，选定后再图生视频，比纯文生视频稳定得多。
- **验收标准**：产品外观与实物一致、无多指/畸形手、文字无乱码、口型与配音对得上、前 3 秒无黑帧与静音、字幕无错别字、时长与版本一致。
- **不通过就回炉**：改提示词里的动作与镜头语言再生成，不要靠剪辑掩盖生成缺陷。

## 复盘口径

素材级指标：3 秒播放率、完播率、CTR、CPC、CVR、CPA、ROAS。判优顺序是**先看 3 秒播放率筛钩子，再看 CTR 筛封面与前 3 秒组合，最后看 CVR/ROAS 判断承接与定价**——把三个环节混在一起看，只会得出「素材不行」这种没法行动的结论。

A/B 纪律：一次只改一个变量；样本不足（未跑出 3–5 个转化）不下结论；同一钩子在不同市场的表现必须分开统计，不要合并。

## 脚本用法

```bash
python3 scripts/video_brief.py products.csv --styles market_styles.csv \
  --hooks hook_patterns.csv --banned banned_words.csv \
  --duration 15 --ratio 9:16,16:9 --hooks-per-sku 2 \
  --out storyboard.csv --out-md brief.md --out-json brief.json --quarantine brief_issues.csv
```

| 参数 | 作用 |
|---|---|
| `--styles` | 市场风格库（语言/平台/节奏/画面/出镜/场景/调性/禁忌） |
| `--hooks` | 钩子模板库，脚本按序轮换，避免所有 SKU 用同一个开头 |
| `--banned` | 禁用词表，扫描卖点、证明、CTA 与全部字幕口播 |
| `--actions` | 自定义动作词表，扩充首帧动态检查的判定词 |
| `--duration` / `--ratio` | 成片时长（15/21/30）与画幅，可传多个比例 |
| `--hooks-per-sku` | 每个 SKU×市场 出几条钩子版本 |

脚本产出的文案里会出现 `{{待填:字段}}`——这是**刻意留出的创意位**（比如「用户最痛的场景」），必须由模型或人工补齐后再进生成队列，脚本不会替你编造卖点与场景。
