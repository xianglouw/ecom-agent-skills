# 阶段 3：选品利润测算

目标：在投流和下单之前，把「这个 SKU 在哪个站点、卖多少钱才不亏」算清楚。产物是**能直接打开的测算表**（CSV 主表 + Markdown 可读表），不是一个结论数字。

典型场景：**美国转运仓模式**——货放在美国仓，按站点分发到墨西哥、巴西、智利、哥伦比亚、阿根廷等拉美市场。同一个 SKU 在不同站点，佣金率、关税门槛、当地币售价、运费档位全都不同，必须逐站点算。

## 利润口径

```text
净利 = 售价 − 平台佣金 − 单件运费 − 关税 − 落地成本
毛利 = 净利 / 售价
```

| 项 | 取值来源 | 注意 |
|---|---|---|
| 售价 | 商品表 `price`（零售）/ `wholesale_price`（批发） | 零售按单件，批发按整箱 |
| 平台佣金 | 站点佣金率 × 售价 | 各站点费率不同，用阶段 1 的费率表或 `--commission` |
| 单件运费 | 运费分段表按「站点 + 计费重量」匹配 | 批发按整箱运费 ÷ 箱规分摊到单件 |
| 关税 | 售价超过免税门槛时，按 `--duty-rate` 全额估算 | 缺税率时必须标记 `duty_threshold_exceeded`，不能默认按 0 算 |
| 落地成本 | 商品表 `cost` | **需自行包含采购、头程、入仓费**；填的是「到手成本」而不是采购价 |

保本价与目标售价由脚本反算，不需要手推：

```text
保本价   = (成本 + 运费) / (1 − 佣金率 [− 关税率])
目标售价 = (成本 + 运费) / (1 − 佣金率 − 关税率 − 目标毛利率)
```

跨过关税门槛时按含税口径重算一次（脚本内部已处理），所以同一个 SKU 可能出现两个保本价区间——这正是「定价卡在门槛上下」时的关键决策点。

## 输入表结构

**商品表**（`--items`）：

| 字段 | 说明 |
|---|---|
| `sku` | 必填，唯一标识 |
| `product_name` | 商品名，仅用于输出可读性 |
| `cost` | 单件落地成本；`--cost-currency RMB` 时配 `--cost-fx` 折算 USD |
| `weight` | 单件重量；单位由 `--item-weight-unit kg\|lb` 指定 |
| `box_qty` | 箱规（一箱几件），批发分摊运费时用；缺省按 1 |
| `price` | 零售售价（USD） |
| `wholesale_price` | 批发售价（USD，单件口径） |

**运费表**（`--freight`，可传多个文件）：

| 字段 | 说明 |
|---|---|
| `site` | 站点代码，如 MX / BR / CL / CO / AR |
| `weight_min` / `weight_max` | 重量区间（lb），也可用一列 `weight_band` 写「0-1」「1-3」这种区间 |
| `freight` | 该档运费 |
| `currency` | 运费币种，非 USD 时用 `--fx` 折算 |

真实运费表常见三种脏数据，脚本都处理了，但取数时要留意：

- **表头上方有说明行**（如「299 比索以下卖家不包邮」）→ 用 `--freight-header-row 2` 指定表头行号，不要手工删行。
- **欧式小数逗号**（`10,84` 表示 10.84）→ 按「逗号后 1–2 位当小数点、3 位当千分位」解析。注意在 CSV 里必须用引号包起来（`"10,84"`），否则会被拆成两列；用分号分隔的欧洲导出文件（`;`）也能自动识别。
- **区间重叠或留空**（`0-1`、`1-3` 边界撞在整数上）→ 命中多档时脚本取**下限更大的一档**（对成本偏保守）；如果区间本身有重叠，先回源表修好。

## 汇率与费率一律手工维护

脚本**不内置任何汇率和费率**，全部由命令行给出，因为：

- 汇率是当天的事，写死就错；
- 各站点佣金率、免税门槛以当期官方公告为准，落到项目里的数字必须带来源和日期。

```bash
--site-currency MX:MXN,BR:BRL,CL:CLP,CO:COP,AR:ARS \
--fx MXN:18.5,BRL:5.4,CLP:950,COP:4100,ARS:1450
```

`--fx` 是「1 USD 兑当地币」，会用来算当地币售价，并判断是否低于免邮门槛。

**下面这张表是结构示例，数值来自一次真实作业但未随附官方出处，落地前必须用当期官方公告复核，不要照抄：**

| 站点/国家 | 币种 | 佣金率（示例） | 免邮门槛（示例） | 进口免税门槛（示例） |
|---|---|---|---|---|
| 墨西哥 MX | MXN | 17% | 299 MXN | 50 USD（超出部分按 IVA 16% 估） |
| 巴西 BR | BRL | 16% | 79 BRL | 79 BRL 档位另有汇率税口径 |
| 智利 CL | CLP | 8% | 28000 CLP | 以官方公告为准 |
| 哥伦比亚 CO | COP | 8% | 60000 COP | 以官方公告为准 |
| 阿根廷 AR | ARS | 13% | 33000 ARS | 以官方公告为准 |

其他市场的进口免税门槛（同样**待复核**）：加拿大 CAD 20、墨西哥 USD 50、英国 £0、澳大利亚 AUD 1000、日本 JPY 10000。这些数字的用途只有一个——判断「售价是否跨过征税门槛」，跨过就必须带关税率算，否则利润虚高。

## 脚本用法

```bash
python3 scripts/selection_profit.py items.csv --freight freight.csv --freight-header-row 2 \
  --rates 费率表.csv --site-currency MX:MXN,BR:BRL --fx MXN:18.5,BRL:5.4 \
  --de-minimis 50 --duty-rate 0.16 --target-margin 0.3 \
  --free-shipping-threshold MX:299,BR:79 --channel both \
  --out selection.csv --out-md selection.md --out-json selection.json \
  --quarantine unpriced.csv
```

关键参数：

| 参数 | 作用 |
|---|---|
| `--channel retail\|wholesale\|both` | 零售按单件算，批发按整箱算并分摊运费 |
| `--de-minimis` + `--duty-rate` | 免税门槛与关税率，两个一起给才能算准 |
| `--target-margin` | 目标毛利率，用来反算目标售价 |
| `--cost-currency RMB --cost-fx 7.2` | 成本表是人民币时折算成 USD |
| `--item-weight-unit kg` | 商品重量用 kg 录入，运费表仍按 lb 匹配（`1 kg = 2.2046226218 lb`） |
| `--free-shipping-threshold MX:299` | 当地币售价低于门槛时在备注里提醒 |

产物：`--out` 明细 CSV（Excel 直接打开）、`--out-md` 按站点分节的 Markdown 测算表（亏损行排最前）、`--out-json` 输出信封、`--quarantine` 算不出来的行及原因。

## 交付时怎么说

- 先给**站点汇总表**（每个站点的可测算行数、负毛利行数、平均/最低毛利），让人一眼看到哪个站点不能做。
- 再给**按站点的 SKU 明细**，亏损和低于目标毛利的排在最前面，并直接给出「保本价 / 目标售价」两列——这样对方拿到表就能改价，不用回来问。
- 把「算不出来的行」单独列出来说明原因（缺重量 / 超运费档 / 缺佣金率 / 缺汇率），而不是静默跳过。
- 负毛利组合是 `high` 级 flag，必须转人工复核，脚本不会替你决定下架或改价。

## 配套交付：美国仓信任背书话术

货在美国仓、发往拉美时，买家最关心「是不是真的从美国发、多久到、坏了怎么办」。上架文案和广告素材需要一组固定话术，中英对照沉淀下来，团队口径才一致：

| 场景 | 中文 | English |
|---|---|---|
| 发货地 | 美国本土仓直发，下单后 1 个工作日内出库 | Ships from our US warehouse within 1 business day |
| 物流时效 | 美国境内 2–5 个工作日送达，全程可查物流单号 | Delivered in 2–5 business days with trackable carrier |
| 退换 | 美国境内 30 天无理由退换，退货地址在美国 | 30-day free returns to a US address |
| 售后 | 工作日 24 小时内回复，支持英语与西班牙语 | Support in English & Spanish, replies within 24h on business days |
| 清关 | 由我们承担清关申报，买家无需额外操作 | We handle customs paperwork — no extra steps for you |

**话术纪律**：时效、退货天数、客服响应时长必须与店铺实际履约能力一致，不能为了转化率写过头的承诺——这类文案属于对外承诺，改动前要过人工确认。适用于其他平台时按该平台规则调整（例如退货窗口、税务表述）。
