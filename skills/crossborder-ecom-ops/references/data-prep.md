# 阶段 2：表格数据整理与口径统一

目标：把各平台后台导出、ERP 导出、供应商报价、人工维护表拼成**一张口径统一、可分析、可复算**的表。跨平台运营里大部分算错都不是算错，而是表头不同、日期格式不同、口径不同。

## 标准字段字典

优先把列名归一到这些标准字段（脚本内置了中英文别名识别，识别不到就 `--map` 显式指定）：

| 标准字段 | 常见别名 |
|---|---|
| `date` | 日期 / 报告日期 / 统计日期 / Date / report_date |
| `sku` | SKU / 商品编码 / 商家编码 / Seller SKU / msku |
| `asin` | ASIN / 子ASIN / listing_id |
| `platform` | 平台 / 渠道 / channel |
| `site` | 站点 / 国家 / marketplace / country |
| `category` | 类目 / 分类 / 一级类目 |
| `campaign` / `ad_group` | 广告活动 / 广告组 / campaign_name |
| `impressions` | 曝光 / 展示 / impressions |
| `clicks` | 点击 / clicks |
| `spend` | 花费 / 广告花费 / 广告费 / cost(广告语境) / ad_spend |
| `orders` | 订单数 / 转化数 / 成交笔数 / conversions |
| `units` | 销量 / 件数 / 数量 / quantity |
| `revenue` | 销售额 / 成交额 / GMV / 收入 / sales |
| `price` | 售价 / 客单价 / unit_price |
| `cost` | 成本 / 采购成本 / 商品成本 / 单位成本 |
| `refund` | 退款 / 退款金额 / 退款率 |
| `currency` | 币种 / 货币 / currency |

`cost` 在广告语境里可能指广告花费，在采购语境里可能指商品成本——**按阶段判断**，不确定时回问用户，不要默认。

## 清洗规则

- **表头**：去空格与换行、统一大小写、全角转半角、去掉括号里的单位注释（另存为字段说明）。
- **文本值**：去首尾空白、内部连续空格压缩为一个、全角字符转半角、统一类目大小写。
- **数字**：去掉货币符号（¥ $ €）、千分位逗号、`%`（转成小数）、`+/-` 号与「万」等单位后缀需换算并记录。
- **日期**：统一 `YYYY-MM-DD`。要能处理 `2026/9/1`、`9/1/2026`、`2026年9月1日`、`20260901`、Excel 序列号（1900 基准）。
- **去重**：按业务主键去重（默认 `sku + date`，投放表用 `date + campaign + sku`），重复行保留哪一行要说明规则（如保留最新导出、保留数值更全的）。
- **缺失值**：区分「真缺失」与「不适用」。数值缺失不要填 0（会把均值算错），标记为空并计入报告。
- **异常值**：负值、极端值（如 999999）、比例超过 1、单价为 0，全部单独列出待人工判断，不要静默修正。
- **币种**：混合币种必须换汇后再聚合，汇率来源与日期写入 `assumptions`。

## 多来源合并

- 主键选择：`sku + site + date` 作为通用主键；没有 SKU 时先用映射表补全再合并。
- 冲突优先级：平台后台导出 > ERP > 人工维护表 > 第三方工具。
- 冲突处理：同一主键出现多个值时不自动覆盖，输出冲突清单（字段、各来源值、建议取值）交人工确认。
- 表结构不一致时：先补列再合并，不要在合并后再补——否则会丢行。

## 输出规范

- CSV 用 **UTF-8 BOM**（Excel 打开中文不乱码），列顺序固定为：维度列 → 数值列 → 来源列。
- 金额保留 2 位小数，比例保留 4 位小数（0.1523）或统一用百分号，同一文件内一致。
- 每次清洗都同时交付三件：`clean.csv`（干净数据）、`clean.json`（输出信封，带清洗报告与风险标记）、字段说明（哪些列被改名、哪些值被转换、哪些行被隔离）。
- 隔离行单独输出（`--quarantine`），不要直接丢掉——被丢掉的行往往就是数据源的配置错误。

## 脚本用法

```bash
python3 scripts/clean_table.py raw.xlsx \
  --out clean.csv --out-json clean.json --quarantine bad_rows.csv \
  --require sku,price --dedupe-on sku,date \
  --map "商品编码=sku" --map "广告花费=spend"
```

报告会给出：读入行数 / 输出行数 / 去重删除行数 / 隔离行数及原因 / 改名映射 / 数值与日期转换次数。先看报告再看数据——报告里隔离行偏多时，通常是源表口径问题，而不是数据脏。
