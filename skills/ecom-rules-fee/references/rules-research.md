# 阶段 1：规则信息搜集与合规费率知识库

目标：把多平台零散的合规规则、费率标准、公告政策、物流规范，变成**可检索、可对照、可引用、可版本化**的结构化知识库，把跨平台查询从「翻几个后台找一两小时」压到分钟级，并让每条结论都能追到来源。

## 检索范围清单

按这四类收集，避免只抓费率漏掉合规条款：

- **费率类**：平台佣金（含类目阶梯）、支付/交易手续费、履约与仓储费、FBA/尾程派送费、长期仓储与移除费、广告费、货币转换费。
- **税务合规类**：VAT/GST/销售税、进口关税、低值免税额度、IOSS/EPR/包装法、原产地与认证要求（CE、FCC、CPC、FDA 等）。
- **物流规范类**：尺寸重量分段与计费重、禁限运品、包装与贴标要求、时效承诺、丢损赔付规则。
- **政策与考核类**：类目准入与禁限售、Listing 政策、广告政策、账号绩效指标与处罚阶梯、退款退货政策、政策过渡期与生效时间。

## 来源优先级

1. 平台官方公告 / 官方费率页 / 卖家后台导出
2. 平台官方文档或招商经理书面答复
3. 物流商与支付服务商官方报价单
4. 用户提供的内部资料（合同、历史账单）
5. 第三方资讯——**只能作为线索**，必须回到 1–4 核实后才能进入知识库

引用格式固定为：`来源名称 + 链接或文件路径 + 适用平台与站点 + 生效日期 + 获取日期`。缺任一字段的数据只能进「待核实」区，不能用于结论。

## 采集与治理流程

1. 确定平台 + 站点 + 类目范围（三者缺一，费率不可比）。
2. 按来源优先级取数；抓取受限时输出「人工取数清单」（要哪个页面的哪些字段、谁去取、什么时候要）。
3. 归一化字段：统一币种、统一比例写法、统一重量单位（kg/g）、统一价格区间边界（含首含尾）。
4. 去重：同一规则多来源冲突时，保留优先级更高的，并记录冲突项与差异。
5. 分类结构化：按「费率 / 税务 / 物流 / 政策」四层，每层再按平台 + 站点 + 类目索引。
6. 落表并打版本：记录 `updated_at`，费率变更时新增版本行而不是覆盖旧行（历史订单要能用当时的费率复算）。

## 合规费率对照表结构

费率表是知识库的核心资产，字段固定如下（可用 CSV/Excel 维护，`scripts/fee_check.py` 直接读）：

| 字段 | 说明 |
|---|---|
| `platform` / `site` | 平台与站点；站点填 `*` 表示全站通用 |
| `category` | 平台原始类目名；填 `*` 表示该类目层级不适用 |
| `price_min` / `price_max` | 适用价格区间（含首含尾），阶梯费率必须拆成多行 |
| `commission_rate` | 佣金比例，用小数（0.15） |
| `payment_rate` | 支付/交易手续费比例 |
| `fulfillment_fee` | 履约/派送费（按件计），带币种 |
| `fba_fee` / `storage_fee` | 仓储类费用，不适用时留空 |
| `tax_rate` | 税率，不适用时留空 |
| `currency` | 该行费用的币种 |
| `condition` | 附加条件（如「仅新卖家首年」「促销期价」） |
| `source` / `effective_date` | 来源与生效日期 |
| `updated_at` | 本行录入或更新时间 |

多平台合计 12 套对照表时，按「平台 × 站点」或「平台 × 业务线」拆分文件，文件名带版本，例如 `amazon_us_fee_v2026-09.csv`。

## 回答规则类问题的输出格式

1. **先给结论表**：平台 / 站点 / 类目 / 费率项 / 数值 / 生效日期。
2. **再给来源**：每条数值对应到 `sources`。
3. **最后给不确定项**：未覆盖的类目、冲突的来源、过渡期规则，明确写出「本项需人工确认」。
4. 涉及费率变动时，同时给新旧数值与差额，便于判断是否需要调价或改成本模型。

数值一律现算现取，不要凭记忆复述——费率记忆错误直接导致定价和利润判断错误。

## 常见坑

- 佣金阶梯按**分段累进**还是**按总价选档**，两者结果不同，必须看官方口径。
- 促销期临时费率、新卖家优惠期、活动报名费容易漏算。
- 平台类目名与内部类目名不一致，映射表要单独维护。
- 费率币种与结算币种不同，需汇率来源与日期。
- 含税与不含税、含运费与不含运费口径混用。
- 政策有过渡期，过渡期内新旧规则并存，按订单实际发生时间选规则。
- 低价商品可能有「小额订单费」或最低收费，按比例算会算少。

## 高扣费风险清单（重点排查）

类目错放、认证或标签不合规、低申报、虚假或绝对化宣传、侵权（商标/专利/版权）、超时发货、绩效指标不达标、违规索评、广告素材违反平台政策、税务未注册或未申报。发现任一项风险时，`flags.level` 至少为 `medium`；涉及罚款、冻结、追缴的判 `high` 并进人工终审。
