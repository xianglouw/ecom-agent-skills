# v0.2.0 — 新增手写单据台账支线，技能增至 9 个

一句话：在原来的七阶段主链路上加了一条「拍照记账」支线，并补上了完整的技能运行链路说明。

## 新增技能：`ecom-receipt-ledger`（阶段 2B 手写单据台账）

面向还在用纸质存根簿的档口与门店：手机拍下手写采购单 / 销售单，自动转成能查、能算、能对账的电子台账。

- **手写简写标准化**：`14pm改17pm`、`15DD屏幕`、`XR` 这类写法对照到标准品名；对不上不猜，进「待映射简写」清单，避免猜错污染盘点与毛利统计。
- **自动算账**：`数量 × 单价` 与单据上写的金额逐笔核对，分「一致 / 小额差异 / 金额不符 / 金额缺失 / 无法复核」五档；金额不符与无法复核直接顶到人工复核清单。
- **采购销售日结**：按天、按月归集采购金额、销售金额、净收益、净收益率、差异笔数、凭证数，输出日结对账报告。
- **凭证回链**：原始单据照片挂到每一行数据上，可点开查验；`--embed-photos` 时在「凭证索引」工作表内嵌缩略图。
- **附带作业手册**：拍照规范、六段式识别提示词、字段契约、起始简写词表、闭店 5 分钟对账 SOP。

## 表格写出器升级（`sheetio.py`，各技能同步）

- 新增**单元格超链接**支持，本地文件自动转 `file:///` 链接。
- 新增**图片嵌入**支持，按 oneCellAnchor 把图片锚进工作表并等比缩放。
- 字段别名扩充到单据场景（`direction` / `doc_no` / `item_raw` / `amount_written` / `photo_path` / `confidence` 等）。
- 修复 `9.5` 这类「月.日」写法被误判成 Excel 日期序列号的问题。

## 现在一共 9 个技能

| 阶段 | 技能 | 做什么 |
| --- | --- | --- |
| 总控 | `crossborder-ecom-ops` | 阶段路由、人机边界、统一输出契约与 Prompt 工程方法 |
| ① | `ecom-rules-fee` | 平台规则与费率检索核算，逐单算实际到手与扣费风险 |
| ② | `ecom-data-prep` | 多来源表格清洗、表头归一、去重与异常行隔离 |
| ②B | `ecom-receipt-ledger` | 手写单据拍照记账、简写标准化、自动算账与采销日结 |
| ③ | `ecom-selection-profit` | 多站点多币种选品利润与定价测算、反算保本价 |
| ④ | `ecom-video-creative` | 广告分镜与生成提示词、前三秒留存检查、任意语种本地化 |
| ⑤ | `ecom-ads-plan` | 投放结构、出价预算、放量节奏与止损判优 |
| ⑥ | `ecom-po-build` | PO 单制作与下单前校验 |
| ⑦ | `ecom-roi-review` | ROAS/ACOS 核算、分组环比、异常归因与周报 |

## 安装

```bash
git clone https://github.com/xianglouw/ecom-agent-skills.git
cp -r ecom-agent-skills/skills/* ~/.codex/skills/
```

运行依赖只有 Python 3.8+ 标准库，不需要 pandas、openpyxl 这类第三方包。每个技能自带示例数据与演示脚本，装完即可跑。
