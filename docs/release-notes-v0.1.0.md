# v0.1.0 — 跨境电商运营 Agent 技能集首发：9 个技能、8 段工作流

首发版本。把跨境电商运营全链路拆成 **9 个可独立安装、可单独调用、可串成流水线**的 Agent 技能：每个技能自带业务手册、确定性核算脚本和风险兜底规则，装进支持 Agent Skills 约定的工具里就能直接用。

运行依赖只有 Python 3.8+ 标准库，**不需要 pandas、openpyxl**。

## 这套技能解决什么问题

| 原来的痛 | 现在怎么做 |
| --- | --- |
| 平台规则和费率太散，查一次要一两小时，漏了就违规扣费 | 分钟级返回，费率留档可复查，缺口与过期来源自动点名 |
| 后台导出、ERP、广告后台的表口径全不一样，每次都要手动清 | 自动统一表头与格式、去重、把有问题的行单独挑出来 |
| 手写采购/销售单据要一笔笔敲进 Excel，算错一个数当天账就对不上 | 拍照识别 → 简写自动对照标准品名 → 数量×单价自动核对，原单照片挂回每一行 |
| 选品定价靠拍脑袋，运费关税把利润吃掉才发现 | 按站点逐行算净利，反算保本价与目标售价，亏损组合单独列出 |
| 广告素材做不出来，做出来前三秒留不住人 | 出分镜脚本与生成提示词，逐条检查前三秒留存，支持任意投放语种 |
| 下单怕出错、复盘说不清为什么亏 | 下单前自动校验金额、起订量、交期；复盘出环比、归因与下周动作 |

每一步都输出**能直接打开的 Excel 表格**（多工作表）和带风险标记的结论；涉及花钱、退款、合规的环节只给判定与依据，落地由人执行。

## 技能按什么顺序跑

主链路：`① 规则费率 → ② 表格清洗 → ③ 选品测算 → ④ 视频素材 → ⑤ 投流结构 → ⑦ ROI 复盘`

- `⑥ PO 单` 从 ③ 分叉，与 ⑤ 汇合进 ⑦
- `②B 单据台账` 是独立支线，随时可跑，产出的标准品名台账与采销数据可喂给 ③ 补货、⑥ 下单、⑦ 核成本
- 复盘结论回流，修正下一轮的选品参数与素材方向
- ① 与 ② 可并行，④ 与 ⑥ 可并行

**完整运行链路**（入口判断表、链路全景图、逐段运行卡片、三种真实跑法）见 [技能运行链路](https://github.com/xianglouw/ecom-agent-skills/blob/main/docs/run-chain.md)。

## 手写单据台账（本版亮点）

面向还在用纸质存根簿的档口与门店：手机拍下手写采购单 / 销售单，自动转成能查、能算、能对账的电子台账。

- **手写简写标准化**：`14pm改17pm`、`15DD屏幕`、`XR` 这类写法对照到标准品名；对不上不猜，进「待映射简写」清单。
- **自动算账**：`数量 × 单价` 与单据上写的金额逐笔核对，分「一致 / 小额差异 / 金额不符 / 金额缺失 / 无法复核」五档；不符与无法复核直接顶到人工复核清单。
- **采购销售日结**：按天、按月归集采购金额、销售金额、净收益、净收益率、差异笔数、凭证数。
- **凭证回链**：原始单据照片挂到每一行，可点开查验；`--embed-photos` 时在「凭证索引」工作表内嵌缩略图。
- **附带作业手册**：拍照规范、六段式识别提示词、字段契约、起始简写词表、闭店 5 分钟对账 SOP。

## 输出与约定

- **统一 JSON 输出信封**：`task / status / confidence / data / flags / need_human_review / sources / assumptions / audit`，便于跨阶段串联、工单回写与事后追责。
- **统一产物参数**：`--out` 主表 CSV（UTF-8 BOM）、`--out-xlsx` Excel 工作簿、`--out-md` Markdown 报告、`--quarantine` 问题行、`--out-json` 输出信封。
- **四级风险分级与人工边界**：涉及资金、退款、合规、平台设置的动作只输出判定与待办，落地永远由人执行。
- **不编造数据**：规则、费率、成本必须带来源与生效日期，查不到就标 `unknown` 交给人工。

## 安装

```bash
git clone https://github.com/xianglouw/ecom-agent-skills.git
cp -r ecom-agent-skills/skills/* ~/.codex/skills/

# 也可以只拿一个（每个技能都是自包含文件夹）
cp -r ecom-agent-skills/skills/ecom-selection-profit ~/.codex/skills/
```

每个技能自带示例数据与 `demo.sh`，进对应目录跑一次即可，示例里刻意埋了脏数据，异常检测路径会真实触发。

## 已知边界

- 费率与政策数据需要按 `as_of` 由人工定期更新，技能只负责结构化与核算，不负责联网抓取。
- 不直连平台后台接口，输入来自后台导出、ERP 或人工维护表。
- 脚本只做确定性计算与校验；归因结论、谈判话术、投放策略等判断性内容由 Agent 结合手册生成，需人工复核。
